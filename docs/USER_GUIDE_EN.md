# The Handyman Accountancy — User Guide (English Master)

**Status:** English authoring draft — not yet approved for in-app publication  
**Audience:** Business owners and operators using The Handyman Accountancy  
**Application interface:** English, left-to-right (LTR). Changing the guide language changes this guide only.  
**Scope:** The 12 user-facing chapters below are the intended help content. The Help ID Registry and button inventory are editorial/source references; they are not the user-facing guide.

> **Important:** The guide describes the current application workflows. It does not perform accounting, submit tax returns, send support requests, or replace professional tax or legal advice. Labels may vary slightly by screen or build. If a control is not visible in your installed version, do not assume it is available.

---

## 1. Getting Started and Main Menu

### What this area is for
The application separates general bookkeeping, job-level project tracking, and company contract/job administration. Choose the area that matches the record you are creating. Do not enter the same transaction in multiple areas unless the workflow explicitly links the records.

### Open the correct workspace
1. Open the application and enter the main menu.
2. Select **Accountancy** for general business income, expenses, customers, invoices and financial reports.
3. Select **Projects** when you need to track the agreed value, costs, payments and profit of a particular job.
4. Select **Company Contracts & Jobs** for work organised under a company and its jobs/work packages.
5. Open **Settings** for business profile, backups, guide language, software update and diagnostics.

### Navigation controls
- **Back** returns to the parent page shown by the application. Use it instead of repeatedly using the browser Back control.
- **Main Menu** returns to the application launcher when that control is shown.
- A section button opens that workspace; it does not itself create or save a record.

### Before entering information
- Confirm that you are in the correct workspace.
- Check the customer, project or company/job to which the information belongs.
- Use the correct date and reporting period.
- Wait for a visible save confirmation before leaving a form.

**Common mistake:** Recording a project cost only in general Accountancy, or recording it in both places without understanding the intended relationship. Project-level and general accounting figures are separate workspaces; follow the workflow for the record you are creating.

## 2. Accountancy — Dashboard and Entries

### Dashboard
The Dashboard is a summary of general accounting records. Use it to review the figures and period shown; it is not a substitute for checking the underlying entries.

1. Open **Accountancy** and review the Dashboard.
2. Check the selected period or date range before interpreting totals.
3. If figures look unexpected, open the underlying records and confirm dates, types and filters.

### Add an income or expense entry
1. Open **Add Entry**.
2. Choose the correct transaction type: **Income** or **Expense**.
3. Enter the transaction date.
4. Select the most accurate available category.
5. Enter the amount using the correct numeric value.
6. Add a clear description and any reference needed to identify the transaction later.
7. Complete any additional fields displayed for the selected type/category.
8. Review the type, date, category and amount.
9. Select **Save** and wait for the confirmation.

### Form controls
- **Save** stores the entered record. Do not assume it succeeded until the application confirms it.
- **Clear Form** clears the current form inputs; it is not a way to delete previously saved records.
- Category selectors open the available category choices. Select the intended category and check that the selected value appears on the form before saving.
- Conditional fields appear only for relevant transaction types or categories. Complete them when they are shown and applicable.

### Correcting an entry
Open the saved record through the records area and use the available edit workflow. Recheck the saved result afterwards. Do not create a second entry merely to correct the first one unless the application’s correction workflow specifically requires it.

**Important:** An invoice marked unpaid is not money received. Do not record unpaid invoice value as received income. Invoice status and actual receipt of money are distinct.

## 3. Expenses and Categories

### Record an expense
1. Open the expense-entry workflow.
2. Confirm that the transaction type is **Expense**.
3. Enter the date the expense occurred or was paid, following your bookkeeping method consistently.
4. Choose the closest matching expense category.
5. Enter the amount and supplier/payee details where requested.
6. Add a description that explains what was purchased and, where relevant, which job it belongs to.
7. Complete any conditional details displayed, such as contractor/subcontractor information.
8. Attach or add receipt information if the screen provides that option.
9. Check the details and select **Save**.

### Choose categories carefully
Use the category that best describes the nature of the cost. The available groups may include **Materials**, **Car Expenses**, **Tools** and **Others**. Keep similar purchases consistently classified so reports are meaningful.

If the category picker contains an **Add New One** option:
1. Open the relevant category group.
2. Choose **Add New One**.
3. Enter a clear category name.
4. Save the new category if prompted.
5. Reopen or check the picker and confirm the new category is available in the intended group.

### Contractor-related expenses
When the selected expense category or workflow displays contractor fields, enter the correct contractor/subcontractor details. Do not enter a supplier as a contractor merely because they issued an invoice; use the field according to its label and purpose.

### Receipt and evidence
Keep the original receipt or invoice outside the application as well where required. An image attached to an entry is supporting evidence, not proof that the amount or category is correct.

**Before saving:** Check the date, amount, category, supplier and job description. A wrong category or date can affect period reports.

## 4. Records, Customers and Invoices

### Review saved records
1. Open **Records**.
2. Select the relevant record type or filter, if available.
3. Check the date range and displayed entries.
4. Open the record to inspect its details.
5. When investigating a discrepancy, compare the individual entries rather than relying only on a dashboard total.

### Save customer details
1. Open **Customers**.
2. Choose the new-customer workflow.
3. Enter the customer's name and the contact/address details requested.
4. Check spelling and contact information.
5. Select **Save Customer**.
6. Confirm that the customer appears in the customer list.

Use an existing customer record where appropriate rather than creating duplicates with slightly different spellings.

### Create an invoice
1. Open **Invoices** and choose the new-invoice workflow.
2. Select the correct customer.
3. Confirm the recipient and billing details.
4. Add each work description as a separate line where appropriate.
5. Enter quantities, rates/prices and any other requested line details.
6. Review line totals, invoice total, dates and payment information.
7. Check the invoice number and recipient.
8. Choose the available save or issue action.

### Save, issue and payment are different
- Saving a draft stores an invoice in the application; it does not mean the invoice has been issued or paid.
- Issuing an invoice makes it an issued document. It does not mean the customer has paid.
- Marking an invoice as paid must reflect an actual payment. Confirm the payment date and method when requested.
- An unpaid invoice is not received income. Do not count it as cash received simply because an invoice exists.

Where the application links a paid invoice to an Accountancy income entry, check the resulting record and avoid entering the same receipt a second time.

### Print or PDF
Use the invoice's available preview/print/PDF workflow. Before sharing:
- Confirm customer and work details.
- Confirm invoice number, date and total.
- Check that the document is the intended draft or final version.
- Review the generated preview before printing or sharing.

## 5. Reports, Tax and Reminders

### Prepare a report
1. Open **Reports**.
2. Select the required reporting period or date range.
3. Check any filters that determine which records are included.
4. Review the displayed totals and, where available, the underlying entries.
5. Use the report's save, preview, print or export action as required.
6. Reopen a saved report from **Saved Reports** when you need to review that stored snapshot.

A report is only as accurate as the records and filters used to prepare it. Confirm that the period and included record types are correct before relying on the result.

### Tax information and calendar
Use the tax-related screens and reminders to organise information and keep track of dates. They are planning and record-keeping tools.

- The application does **not** automatically submit a Self Assessment return to HMRC.
- A tax calendar entry does **not** file a return or make a payment.
- A reminder does **not** guarantee that HMRC has received anything.
- Check official HMRC records and deadlines independently and obtain professional advice where needed.

### Print Preview
Open the report preview and inspect all pages before printing or saving. Check that tables, totals and date ranges are visible. If the preview appears incomplete, do not treat it as a complete report; return to the report and verify the selected period and records.

## 6. Backup and Restore

### Create a backup
1. Open **Settings → Backup & Restore**.
2. Identify the data area you intend to back up.
3. Select the relevant backup action.
4. Wait for the completion message and any download to finish.
5. Confirm that the downloaded file exists and can be retained.
6. Store a copy somewhere separate from the device.

Create backups before significant maintenance or data changes. Keep more than one dated backup where practical and do not overwrite your only known-good copy.

### Restore data — read carefully
Restore is a replacement operation, not a routine refresh.

1. Confirm exactly which data area is the restore destination.
2. Locate the intended backup file.
3. Verify that it is the correct backup and is not damaged or from the wrong business/version.
4. Read the confirmation screen and understand what existing data will be replaced.
5. Proceed only when replacement is intentional and you have a separate safety copy of the current data.
6. Wait for the restore process and its confirmation to finish.
7. Review the restored records and totals.

**Do not restore just because a screen looks empty or a total appears wrong.** First check the selected module, filters, date range and diagnostics. Restoring the wrong backup can replace valid current records.

## 7. Monitor and Diagnostics

### Purpose
**Monitor & Diagnostics** helps inspect application version information, activity information and available storage/integrity checks. Use it to investigate a problem; it is not an accounting-entry screen.

### Basic checks
1. Open **Settings → Monitor & Diagnostics**.
2. Review the displayed version/build details.
3. Check the activity information and any error messages.
4. Run the local self-check when troubleshooting.
5. Read the result and note any reported failure.
6. Export an activity log only when it is useful for diagnosis.

### Exporting diagnostic information
An exported log or diagnostic report may contain business or operational information. Store it securely and share it only with a person who needs it to investigate the issue.

A diagnostic PASS is evidence for the checks that were actually run; it does not prove that every application workflow or every saved record is correct.

**Do not:** edit database files, delete records, reset storage or restore a backup as an experiment.

## 8. Business Workspace and Projects

### Create and organise a project
1. Open **Projects**.
2. Choose the new-project action.
3. Enter the project name and the details requested by the form.
4. Enter the agreed project price/value where requested.
5. Review the customer/job information and save.
6. Open the project and add sub-projects or work sections when the job needs separate cost tracking.

Use one project per distinct job or contract where that reflects the real work. Give sub-projects clear names so that costs and payments can be traced.

### Record project activity
Within the correct project or sub-project:
1. Open the relevant income, expense, payment or cost workflow.
2. Confirm the project and sub-project shown.
3. Enter the date, description and amount.
4. Complete partner-share, worker or contractor details when the workflow requests them.
5. Review the entry and save.
6. Reopen the project summary and confirm that the entry appears in the intended place.

### Review project performance
Check the agreed value, recorded income, expenses, payments and any displayed profit calculation. Confirm that all relevant costs have been entered and that amounts are assigned to the correct project/sub-project.

**Important:** Project figures are maintained separately from general Accountancy. Do not assume that adding a project cost automatically creates a general expense entry, or vice versa. Follow the intended workflow and avoid duplicate recording.

## 9. Company Contracts and Jobs

### Set up a company and job
1. Open **Company Contracts & Jobs**.
2. Select an existing company or use the available company-creation action.
3. Check the company identity and details.
4. Create or select the relevant job under that company.
5. Enter the job details and save.
6. Add work packages/sections where the job needs to be divided into manageable parts.

Keep company, job and work-package names clear and consistent. Confirm the selected company and job before entering costs or payments.

### Record costs and payments
1. Open the correct job or work package.
2. Choose the relevant expense, payment or income action.
3. Enter the date, description and amount.
4. Add the supplier, worker, contractor or other details requested by the form.
5. Save and check that the record appears under the correct job/work package.

### Review a job
Review the job's work packages, recorded costs, payments and totals. Resolve missing or misallocated entries before marking work complete. A completion status is an administrative record; it does not itself confirm that every supplier or worker has been paid.

## 10. Contract Management

### Create a contract
1. Open **Contract Management**.
2. Start a new contract or open the relevant existing contract.
3. Enter or select the customer/party details.
4. Enter the job/property details and scope of work.
5. Review the contract terms, dates, amounts and payment stages.
6. Save the contract.
7. Reopen the saved contract and check that the details are correct.

### Review before issuing
Check all party names, addresses, job scope, exclusions, prices, payment stages, dates and other terms. Do not rely on an automatically drafted clause without understanding it. Obtain appropriate legal advice for important or disputed contractual terms.

If a writing assistant is used to prepare wording, treat its output as a draft. Check that it reflects the actual agreement and applicable requirements before sending or signing.

### Amendments
Do not silently overwrite an agreed contract in a way that hides what changed. Follow the available edit/version process and keep a separate record of material variations or approvals where appropriate.

## 11. Settings, Profile and Software Update

### Business profile and logo
1. Open **Settings → Profile & Logo**.
2. Review the business name and owner/contact details.
3. Enter or correct the details.
4. Add or replace the business logo if required.
5. Check the logo preview and any size guidance shown.
6. Select **Save Profile** and wait for confirmation.

Use accurate business details because they may appear on generated documents. Use **Remove Logo** only when you intentionally want to remove the saved logo.

### User Guide language
1. Open **Settings → Help**.
2. Open **User Guide language**.
3. Select the preferred guide language.
4. Wait for the saved-status message.
5. Open **User Guide** to view the selected language.

This setting changes the guide only. Application menus, forms, accounting records, projects and reports remain English and left-to-right.

### Software Update
1. Open **Settings → Software Update**.
2. Check the installed version shown.
3. Use the available online check to see whether a newer version is published.
4. Read the update information before installing.
5. After an update, refresh/reopen the application and verify the installed version.

Do not assume that a newer version is installed merely because an update check was opened. Confirm the resulting version/build shown by the application.

### Factory Reset
**Factory Reset is destructive.** It is not a normal troubleshooting step. Do not open or confirm it unless you deliberately intend to replace/reset the current application data, have a verified backup, and understand the consequences. If data appear missing, use the non-destructive checks in Chapter 12 first.

## 12. Data Safety and Troubleshooting

### If a record appears missing
1. Do not immediately reset or restore.
2. Refresh the page once.
3. Confirm that you opened the correct workspace (Accountancy, Projects or Company Contracts & Jobs).
4. Check the selected date range, filters and record type.
5. Search the relevant customer, project, job or record list.
6. Open Monitor & Diagnostics and review available checks.
7. Preserve existing backups while investigating.

### If saving appears to fail
- Wait for the save process to finish.
- Read any message displayed by the application.
- Check whether the record is already present before trying again; repeated taps can create duplicate entries in some workflows.
- If the record is not present and an error is shown, note the exact message and the steps that led to it.
- Do not delete or reset data to clear an error.

### If a report or PDF looks incomplete
- Recheck the reporting period and filters.
- Confirm the underlying records are present.
- Reopen the preview and inspect every page.
- If the output remains incomplete, keep the original records unchanged and report the issue with the relevant screen, date range and error details.

### Contact Us
The current **Contact Us** form saves a support message locally as a draft on the device. **It does not send the message to the developer or support team.** Keep a separate copy of important details and use an available external contact route if you need to send the request now.

### Safe troubleshooting information to provide
When reporting a problem, include:
- The page/workspace where it happened.
- The action you selected and the steps immediately before the problem.
- The date/time and reporting period, if relevant.
- The exact error message.
- The application version/build shown in Monitor or Software Update.
- Whether the problem repeats after one refresh.

Do not include passwords, full bank details or unnecessary personal/customer information in a diagnostic message.
